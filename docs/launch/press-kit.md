## Boilerplate

### 50 words

Snug is a free Chrome extension that exports, imports and backs up your
bookmarks entirely on your device. Move them between browsers exactly as you
left them, in six formats, with an import preview and undo. It is open source,
needs no account, shows no ads and makes no network calls.

### 150 words

Snug is a free, open source Chrome extension that exports, imports and backs up
your bookmarks entirely on your device. It was called Bookmark Import/Export
until the 2.0 rename. Export the whole tree or only chosen folders in HTML,
JSON, CSV, Markdown, OPML or XBEL. Import with a preview first, then merge,
replace, or add everything to a new folder, and undo a replace from a Safety
snapshot. A Duplicates page and Skip duplicates keep a library tidy, and
scheduled Auto-export saves backups to Downloads or a folder you choose with
Retention and a failure notification. Snug has no account, no ads and no data
collection, and it makes zero network calls. Everything runs inside the
extension itself. The source is public under the MIT license. It works in Chrome
and other Chromium browsers and comes in 10 languages. Snug does not sync and
has no cloud, so your bookmarks never leave the browser.

## Fact sheet

| Item           | Detail                                                                                                                           |
| -------------- | -------------------------------------------------------------------------------------------------------------------------------- |
| Name           | Snug, formerly Bookmark Import/Export (renamed in 2.0)                                                                           |
| What it is     | Free Chrome extension to export, import and back up bookmarks                                                                    |
| Licence        | Open source (MIT)                                                                                                                |
| Data           | On your device. No account, no ads, no data collection, zero network calls                                                       |
| Formats        | HTML, JSON, CSV, Markdown, OPML, XBEL. Markdown and OPML are export-only                                                         |
| Import         | Several files at once, with an itemized preview; merge, replace or new folder; latest five Safety snapshots and undo for replace |

| Cleanup        | Duplicates page and Skip duplicates on import                                                                                    |
| Browsers       | Chrome and other Chromium browsers (Chrome 119 or later, Edge, Brave, Opera)                                                     |
