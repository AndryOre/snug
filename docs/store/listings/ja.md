# Chrome Web Store listing: ja

## Title

Snug: ブックマークの書き出し・読み込み・バックアップ

## Summary

ブックマークを一般的な形式で書き出し、ChromeやSafariから読み込み、自動バックアップ。すべて端末内。

## Detailed description

Snugは、ブックマークをブラウザー間でそのままの状態で移せます。データはどこにも送信されず、アカウントも不要です。

ブックマーク全体、または選んだフォルダーだけを、HTMLやJSONなどの一般的な形式で書き出せます。ほかのブックマーク管理ツールのファイル、Chromeプロファイルの Bookmarks ファイル、Safariのブックマークを読み込め、まず追加・スキップ・削除される内容をプレビューで確認できます。複数のファイルをまとめて選ぶか、ドロップして読み込めます。そのうえで、既存のブックマークと統合するか、完全に置き換えるか、新しいフォルダーにまとめて入れるかを、毎回自分で選べます。

置き換えの前には、Snugがブックマークの安全スナップショットを保存するので、元に戻せます。最新の5件は端末内に保存されます。「重複」ページでは重複したブックマークを見つけ、選んだものだけを削除できます。読み込み時に重複をスキップすることもできます。

スケジュールを一度設定すれば、毎時、毎日、毎週などの間隔で、選んだ形式のバックアップがダウンロードフォルダーまたは選んだフォルダーに自動で保存されます。保持設定で最新のバックアップだけを残し、失敗したときは通知でお知らせします。ファイル名には日付と時刻を自動で含められます。

Snugはすべて端末内で動作します。アカウント、クラウド、サーバーは不要です。すべての操作はブラウザー自身のブックマークを直接読み書きするだけ。それが信頼の理由のすべてです。ブックマークツリーはキーボードとスクリーンリーダーで完全に操作でき、10言語に対応しています。Chromeと、Chromiumベースの他のブラウザー（Edge、Opera、Brave）で、同じストアページから利用できます。
