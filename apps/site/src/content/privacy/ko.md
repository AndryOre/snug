# Snug 개인정보 처리방침

최종 업데이트: 2026년 10월 10일

## 소개

Snug는 여러분의 개인정보를 보호하기 위해 최선을 다합니다. 이 개인정보 처리방침은
당사의 브라우저 확장 프로그램을 통해 받는 정보의 수집, 사용, 공개에 관한 당사의
방침을 설명합니다.

## 정보 수집 및 사용

Snug는 사용자의 개인정보를 수집, 저장, 전송하지 않습니다. 당사의 확장 프로그램은
전적으로 브라우저 안에서 작동하며 외부 서버로 어떤 데이터도 보내지 않습니다.

### 북마크 데이터

- 확장 프로그램이 브라우저 북마크에 접근하는 것은 HTML, JSON, CSV, Markdown,
  OPML, XBEL 파일로 내보내거나, HTML, JSON, CSV, XBEL 파일, Chrome 프로필의
  `Bookmarks` 파일 또는 Safari 내보내기 파일에서 북마크를 가져오는 목적에
  한정됩니다. 중복 페이지도 같은 주소의 사본을 찾기 위해 북마크를 읽으며,
  사용자가 확인한 경우에만 삭제합니다.
- 이러한 접근은 사용자가 가져오기나 내보내기를 직접 시작할 때, 또는 사용자가
  설정한 예약 자동 내보내기가 실행될 때만 이루어집니다(아래 '자동 내보내기'
  참조).
- 북마크 데이터는 사용자의 기기에서 로컬로 처리되며 당사나 제3자에게 전송되지
  않습니다.

### 파비콘

- 북마크 옆에 사이트 아이콘을 표시하기 위해 확장 프로그램은 브라우저에 내장된
  `_favicon` API로 파비콘을 읽습니다. 이는 브라우저가 이미 캐시해 둔 파비콘을
  조회하는 것이며, 당사나 북마크된 사이트로 어떤 네트워크 요청도 보내지
  않습니다.

### 자동 내보내기

- 자동 내보내기를 켜면 북마크를 예약된 일정에 따라 내보낼 수 있습니다(선택
  사항). 켜 두면 확장 프로그램이 사용자가 설정한 간격으로 북마크를 내보내고,
  저장 위치를 묻는 창 없이 생성된 파일을 저장합니다. 기본적으로는 브라우저의
  다운로드 기능을 사용해 기기의 다운로드 폴더에 바로 저장됩니다. 사용자 지정
  폴더를 선택하면 대신 사용자가 컴퓨터에서 고른 폴더에 브라우저의 File System
  Access API를 통해 기록됩니다.
- 이는 사용자가 자동 내보내기를 직접 켜고 일정을 설정한 경우에만 이루어지며,
  기본적으로는 꺼져 있습니다.
- 보관: 자동 내보내기에 성공할 때마다 Snug는 사용자가 정한 개수(기본값 10개,
  0이면 모두 보관)를 초과하는, 자신이 내보낸 가장 오래된 파일을 삭제합니다.
  다운로드 폴더나 사용자 지정 폴더에서 Snug가 직접 저장한 파일만 삭제하며, 다른
  파일은 건드리지 않습니다.
- 사용자 지정 폴더: 사용자가 선택한 폴더는 자동 내보내기가 계속 그 폴더에 기록할
  수 있도록 기기에 기억됩니다. 브라우저가 접근을 다시 확인해 달라고 요청할 수
  있습니다. 파일은 어떤 서버로도 전송되지 않으며, 폴더를 선택하는 데 추가 권한은
  필요하지 않습니다.
- 알림: 자동 내보내기에 실패하면 Snug가 기기에 이유를 담은 시스템 알림을
  표시합니다. 자동 내보내기 페이지에서 이 알림을 끌 수 있습니다. 성공했을 때는
  알리지 않으며, 알림 내용이 기기 밖으로 나가는 일은 없습니다.

## 데이터 저장

- Snug는 북마크를 포함한 어떤 사용자 데이터도 외부 서버에 저장하지 않습니다.
- 내보내기(수동 또는 자동) 중에 생성되는 파일은 로컬 기기에 바로 저장됩니다.
  다운로드 폴더에는 브라우저의 다운로드 기능을 통해, 자동 내보내기의 경우
  사용자가 선택한 사용자 지정 폴더에는 브라우저의 File System Access API를 통해
  저장됩니다. 수동 내보내기는 표준 `<a download>` 링크를 사용하므로 `downloads`
  권한이 필요하지 않습니다. 자동 내보내기와 안전 스냅샷 파일에는 `downloads`
  권한을 사용합니다.
- 확장 프로그램은 테마, 표시 옵션, 내보내기 옵션, 파일 이름 템플릿, 자동
  내보내기 설정 같은 로컬 환경설정을 브라우저의 로컬 스토리지(`storage.local`)에
  저장합니다. 이 데이터는 기기에 남으며 어디로도 전송되지 않습니다.
- 자동 내보내기에 사용자 지정 폴더를 선택하면 Snug는 그 폴더에 대한 브라우저의
  참조(폴더 핸들이며, 북마크나 폴더 내용이 아닙니다)를 확장 프로그램의 로컬
  브라우저 저장소(IndexedDB)에 보관합니다. 이 참조는 기기에 남으며 어디로도
  전송되지 않습니다.
- Snug는 첫 내보내기에 성공한 뒤, 설치한 스토어(Chrome 웹 스토어 또는 Microsoft
  Edge 부가 기능)에서 확장 프로그램 리뷰를 남겨 달라고 안내하는, 한 번만
  표시되고 닫을 수 있는 카드를 팝업에 보여 줄 수 있습니다. 한 번만 표시하기 위해
  Snug는 카드가 표시 가능해진 시각과 사용자가 닫은 시각, 이렇게 두 개의 로컬
  타임스탬프를 `storage.local`에 저장합니다. 여기에는 북마크 내용, 개인정보,
  식별자가 전혀 없으며 어디로도 전송되지 않습니다. 이 카드는 링크일 뿐입니다.
  스토어 페이지를 열지는 사용자가 선택하며, Snug 자체는 이를 위해 네트워크
  요청을 보내지 않습니다.
- 모든 '복원 — 바꾸기' 가져오기 전과 설정에서 직접 스냅샷을 만들 때마다, Snug는
  가져오기를 되돌릴 수 있도록 북마크바와 기타 북마크의 안전 스냅샷을 저장합니다.
  이때 북마크 내용(제목, 주소, 폴더 구조)이 브라우저의 로컬 스토리지에 저장되며
  최근 5개의 스냅샷이 유지되고, 각 스냅샷은 다운로드 폴더에도 파일로 저장됩니다.
  이 데이터는 기기 밖으로 나가지 않습니다.

## 권한

Snug는 다음 브라우저 권한을 요청하며, 각 권한은 설명된 목적에만 사용됩니다.

| 권한               | 목적                                                                                                                                     |
| ------------------ | ---------------------------------------------------------------------------------------------------------------------------------------- |
| `bookmarks`        | 가져오기와 내보내기를 지원하기 위해 브라우저 북마크를 읽고 씁니다.                                                                       |
| `favicon`          | 브라우저에 내장된 `_favicon` API로 북마크 옆에 사이트 아이콘을 표시합니다.                                                               |
| `storage`          | 로컬 환경설정을 기기에 저장합니다.                                                                                                       |
| `alarms`           | 설정한 간격에 맞춰 북마크 자동 내보내기를 예약하고 실행합니다.                                                                           |
| `downloads`        | 자동 내보내기와 안전 스냅샷 파일을 기기에 저장하고, Snug가 만든 오래된 자동 내보내기 파일을 삭제합니다(보관).                            |
| `notifications`    | 자동 내보내기에 실패하면 기기에 알림을 표시합니다. 끌 수 있습니다.                                                                       |
| `unlimitedStorage` | 북마크의 최근 안전 스냅샷 5개를 기기에 보관합니다. 북마크가 많으면 용량이 클 수 있습니다.                                                |
| `offscreen`        | 자동 내보내기를 다운로드 가능한 파일로 만들 수 있도록 잠시만 존재하는 숨겨진 문서를 만듭니다. UI가 없고 원격 콘텐츠도 불러오지 않습니다. |

## 제3자 서비스

당사의 확장 프로그램은 제3자 서비스나 분석 도구와 연동하거나 이를 사용하지
않습니다.

## 이 개인정보 처리방침의 변경

당사는 개인정보 처리방침을 수시로 업데이트할 수 있습니다. 변경 사항은 이
페이지에 새 개인정보 처리방침을 게시하고 방침 상단의 '최종 업데이트' 날짜를
갱신하는 방식으로 알립니다.
