# Политика конфиденциальности Snug

Последнее обновление: 10 октября 2026 г.

## Введение

Snug стремится защищать вашу конфиденциальность. В этой Политике
конфиденциальности описано, как мы собираем, используем и раскрываем информацию,
которую получаем через наше расширение для браузера.

## Сбор и использование информации

Snug не собирает, не хранит и не передаёт никаких персональных данных своих
пользователей. Наше расширение работает целиком внутри вашего браузера и не
отправляет данные на внешние серверы.

### Данные закладок

- Расширение обращается к закладкам вашего браузера только для того, чтобы
  экспортировать их в файлы HTML, JSON, CSV, Markdown, OPML или XBEL, либо
  импортировать из файлов HTML, JSON, CSV или XBEL, файла `Bookmarks` профиля
  Chrome или экспорта Safari. Страница «Дубликаты» также читает ваши закладки,
  чтобы найти копии одного и того же адреса, и удаляет их, только когда вы это
  подтверждаете.
- Такой доступ происходит только тогда, когда вы явно запускаете импорт или
  экспорт либо когда выполняется настроенный вами автоэкспорт по расписанию (см.
  раздел «Автоэкспорт» ниже).
- Данные ваших закладок обрабатываются локально на вашем устройстве и не
  передаются ни нам, ни третьим лицам.

### Фавиконки

- Чтобы показывать значки сайтов рядом с закладками, расширение считывает
  фавиконки через встроенный в браузер API `_favicon`. Этот запрос ищет
  фавиконки, которые ваш браузер уже сохранил в кэше, и не отправляет сетевых
  запросов ни нам, ни сайтам из закладок.

### Автоэкспорт

- При желании вы можете включить автоэкспорт закладок по расписанию. После
  включения расширение экспортирует ваши закладки с заданным вами интервалом и
  сохраняет получившиеся файлы, не показывая диалог выбора места сохранения. По
  умолчанию они записываются прямо в папку «Загрузки» на вашем устройстве
  средствами браузера. Если вы выберете пользовательскую папку, файлы
  записываются вместо этого в папку, которую вы выбрали на своём компьютере,
  через File System Access API браузера.
- Это происходит только если вы явно включили автоэкспорт и задали расписание;
  по умолчанию он выключен.
- Хранение: после каждого успешного автоэкспорта Snug удаляет собственные
  экспортированные файлы старше заданного вами количества (по умолчанию 10; 0
  сохраняет все). Он удаляет только файлы, которые сохранил сам, в папке
  «Загрузки» или в вашей пользовательской папке, и никогда не трогает другие
  файлы.
- Пользовательская папка: выбранная вами папка запоминается на вашем устройстве,
  чтобы автоэкспорт мог и дальше записывать в неё файлы. Браузер может снова
  попросить вас подтвердить доступ. Файлы никогда не отправляются ни на какой
  сервер, а выбор папки не требует никаких дополнительных разрешений.
- Уведомления: если автоэкспорт завершился ошибкой, Snug показывает на вашем
  устройстве системное уведомление с причиной. Его можно отключить на странице
  «Автоэкспорт». При успешном экспорте уведомления никогда не появляются, а
  содержимое уведомлений не покидает ваше устройство.

## Хранение данных

- Snug не хранит никакие пользовательские данные, включая закладки, на внешних
  серверах.
- Файлы, создаваемые при экспорте (ручном или автоматическом), сохраняются прямо
  на вашем локальном устройстве: в папку «Загрузки» средствами загрузки вашего
  браузера или, при автоматическом экспорте, в выбранную вами пользовательскую
  папку через File System Access API браузера. Ручной экспорт использует
  стандартную ссылку `<a download>` и не требует разрешения `downloads`;
  автоматический экспорт и файл страхового снимка используют разрешение
  `downloads`.
- Расширение сохраняет ваши локальные настройки и предпочтения, такие как тема,
  параметры отображения, параметры экспорта, шаблон имени файла и настройки
  автоэкспорта, в локальном хранилище браузера (`storage.local`). Эти данные
  остаются на вашем устройстве и никуда не передаются.
- Если вы выберете пользовательскую папку для автоэкспорта, Snug хранит ссылку
  браузера на эту папку (дескриптор папки, а не ваши закладки или содержимое
  папки) в локальном хранилище браузера расширения (IndexedDB). Она остаётся на
  вашем устройстве и никуда не передаётся.
- Snug может показать во всплывающем окне разовую карточку, которую можно
  закрыть, с предложением оценить расширение в магазине, из которого оно было
  установлено (Chrome Web Store или Microsoft Edge Add-ons), после вашего
  первого успешного экспорта. Чтобы показать её только один раз, Snug хранит в
  `storage.local` две локальные временные метки: когда карточка стала доступна и
  когда вы её закрыли. В них нет содержимого закладок, личной информации и
  идентификаторов, и они никуда не передаются. Карточка — это просто ссылка:
  открывать ли страницу магазина, решаете вы, а сам Snug не делает для этого
  никаких сетевых запросов.
- Перед каждым импортом в режиме «Восстановить — заменить», а также всякий раз,
  когда вы сами создаёте его в настройках, Snug сохраняет страховой снимок вашей
  панели закладок и остальных закладок, чтобы импорт можно было отменить. При
  этом содержимое ваших закладок (названия, адреса и структура папок)
  сохраняется локально в локальном хранилище браузера, причём хранятся пять
  последних снимков, а каждый снимок дополнительно сохраняется как файл в вашей
  папке «Загрузки». Оно никогда не покидает ваше устройство.

## Разрешения

Snug запрашивает следующие разрешения браузера, и каждое используется только для
описанной цели:

| Разрешение         | Назначение                                                                                                                                                   |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `bookmarks`        | Чтение и запись закладок вашего браузера для поддержки импорта и экспорта.                                                                                   |
| `favicon`          | Показ значков сайтов рядом с закладками через встроенный в браузер API `_favicon`.                                                                           |
| `storage`          | Сохранение ваших локальных настроек и предпочтений на вашем устройстве.                                                                                      |
| `alarms`           | Планирование и запуск автоматического экспорта закладок с заданным интервалом.                                                                               |
| `downloads`        | Сохранение на вашем устройстве файлов автоэкспорта и страховых снимков, а также удаление старых файлов автоэкспорта Snug (Хранение).                         |
| `notifications`    | Показ уведомления на вашем устройстве, если автоэкспорт завершился ошибкой. Его можно отключить.                                                             |
| `unlimitedStorage` | Хранение на вашем устройстве пяти последних страховых снимков ваших закладок, которые могут быть большими при крупных библиотеках.                           |
| `offscreen`        | Создание недолговечного скрытого документа, чтобы автоэкспорт превращался в загружаемый файл. У него нет интерфейса, и он не загружает удалённое содержимое. |

## Сторонние сервисы

Наше расширение не интегрируется с какими-либо сторонними сервисами или
инструментами аналитики и не использует их.

## Изменения в этой Политике конфиденциальности

Мы можем время от времени обновлять нашу Политику конфиденциальности. Об
изменениях мы сообщим, опубликовав новую Политику конфиденциальности на этой
странице и обновив дату «Последнее обновление» в начале этой политики.
