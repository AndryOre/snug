# Snug のプライバシーポリシー

最終更新日：2026年10月10日

## はじめに

Snug は、お客様のプライバシーの保護に努めています。本プライバシーポリシーは、当社のブラウザー拡張機能を通じて受け取る情報の収集、利用、開示に関する方針を説明するものです。

## 情報の収集と利用

Snug は、ユーザーの個人情報を収集、保存、送信しません。当社の拡張機能はすべてお使いのブラウザー内で動作し、外部サーバーにデータを送信することはありません。

### ブックマークのデータ

- 拡張機能がブックマークにアクセスするのは、HTML、JSON、CSV、Markdown、OPML、XBEL ファイルへ書き出す場合、または HTML、JSON、CSV、XBEL ファイル、Chrome プロファイルの
  `Bookmarks`
  ファイル、Safari のエクスポートからブックマークを読み込む場合に限られます。「重複」ページでも、同じアドレスのコピーを見つけるためにブックマークを読み取り、削除するのはお客様が確認した場合のみです。
- このアクセスが行われるのは、お客様が読み込みまたは書き出しを明示的に開始したとき、またはお客様が設定したスケジュール済みの自動書き出しが実行されるときだけです（下記「自動書き出し」を参照）。
- ブックマークのデータはお使いのデバイス上でローカルに処理され、当社や第三者に送信されることはありません。

### ファビコン

- ブックマークの横にサイトのアイコンを表示するため、拡張機能はブラウザー組み込みの
  `_favicon`
  API を通じてファビコンを読み取ります。これはブラウザーがすでにキャッシュしているファビコンを参照するもので、当社やブックマーク先のサイトへネットワークリクエストを送ることはありません。

### 自動書き出し

- ブックマークの自動書き出しを、任意でスケジュール実行できます。有効にすると、拡張機能は設定した間隔でブックマークを書き出し、保存先を尋ねるダイアログを表示せずにファイルを保存します。既定では、ブラウザーのダウンロード機能を使って、お使いのデバイスの「ダウンロード」フォルダーに直接保存されます。カスタムフォルダーを選択した場合は、代わりに、お使いのコンピューター上で選んだフォルダーに、ブラウザーの File
  System Access API を通じて書き込まれます。
- これは、お客様が自動書き出しを明示的に有効にしてスケジュールを設定した場合にのみ行われます。初期状態では無効です。
- 保持：自動書き出しが成功するたびに、Snug は設定した件数（既定は 10 件、0 ですべて保持）を超えた、自身が書き出した古いファイルを削除します。削除するのは Snug 自身が保存したファイルのみで、「ダウンロード」フォルダーまたはカスタムフォルダー内のそれ以外のファイルには一切触れません。
- カスタムフォルダー：選択したフォルダーはお使いのデバイスに記憶され、自動書き出しがそこへ書き込みを続けられるようにします。ブラウザーからアクセスの再確認を求められることがあります。ファイルがサーバーに送信されることはなく、フォルダーを選択しても追加の権限は必要ありません。
- 通知：自動書き出しが失敗した場合、Snug はその理由をデバイス上のシステム通知で表示します。この通知は「自動書き出し」ページでオフにできます。成功した場合は通知されず、通知の内容がデバイスの外に出ることもありません。

## データの保存

- Snug は、ブックマークを含むいかなるユーザーデータも外部サーバーに保存しません。
- 書き出し（手動または自動）で作成されるファイルは、お使いのローカルデバイスに直接保存されます。保存先は、ブラウザーのダウンロード機能による「ダウンロード」フォルダーか、自動書き出しの場合は、選択したカスタムフォルダー（ブラウザーの File
  System Access API を通じて書き込み）です。手動書き出しは標準の `<a download>`
  リンクを使用し、`downloads`
  権限は不要です。自動書き出しと安全スナップショットのファイルには `downloads`
  権限を使用します。
- 拡張機能は、テーマ、表示オプション、書き出しオプション、ファイル名テンプレート、自動書き出しの設定といったローカルの環境設定を、ブラウザーのローカルストレージ（`storage.local`）に保存します。このデータはお使いのデバイス内にとどまり、どこにも送信されません。
- 自動書き出し用にカスタムフォルダーを選択した場合、Snug はそのフォルダーへのブラウザーの参照（フォルダーハンドル。ブックマークやフォルダーの内容ではありません）を、拡張機能のローカルのブラウザーストレージ（IndexedDB）に保存します。この参照はお使いのデバイス内にとどまり、どこにも送信されません。
- Snug は、最初の書き出しが成功した後、インストール元のストア（Chrome ウェブストアまたは Microsoft
  Edge アドオン）で拡張機能のレビューを促す、一度だけ表示される閉じられるカードをポップアップに表示することがあります。表示を一度だけにするため、Snug は 2 つのローカルのタイムスタンプ（カードが表示可能になった時刻と、お客様が閉じた時刻）を
  `storage.local`
  に保存します。これらにはブックマークの内容、個人情報、識別子は含まれず、どこにも送信されません。このカードは単なるリンクです。ストアのページを開くかどうかはお客様の判断で、Snug 自体はそのためのネットワークリクエストを行いません。
- 「復元 — 置き換え」によるすべての読み込みの前、および設定で任意に取得するときに、Snug は読み込みを元に戻せるよう、ブックマークバーとその他のブックマークの安全スナップショットを保存します。ブックマークの内容（タイトル、アドレス、フォルダー構造）がブラウザーのローカルストレージに保存され、最新の 5 件が保持されるほか、それぞれが「ダウンロード」フォルダーにファイルとしても保存されます。デバイスの外に出ることはありません。

## 権限

Snug は次のブラウザー権限を要求します。いずれも、記載した目的にのみ使用されます。

| 権限               | 目的                                                                                                                                                    |
| ------------------ | ------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `bookmarks`        | 読み込みと書き出しに対応するため、ブラウザーのブックマークを読み書きします。                                                                            |
| `favicon`          | ブラウザー組み込みの `_favicon` API を通じて、ブックマークの横にサイトのアイコンを表示します。                                                          |
| `storage`          | お客様のローカルの環境設定をデバイスに保存します。                                                                                                      |
| `alarms`           | 設定された間隔で、ブックマークの自動書き出しをスケジュールして実行します。                                                                              |
| `downloads`        | 自動書き出しと安全スナップショットのファイルをデバイスに保存し、Snug 自身の古い自動書き出しファイルを削除します（保持）。                               |
| `notifications`    | 自動書き出しが失敗したときに、デバイス上で通知を表示します。オフにできます。                                                                            |
| `unlimitedStorage` | ブックマークの最新 5 件の安全スナップショットをデバイスに保存します。ブックマークが多い場合、サイズが大きくなることがあります。                         |
| `offscreen`        | 自動書き出しをダウンロード可能なファイルに変換するため、短時間だけ存続する非表示のドキュメントを作成します。UI はなく、外部コンテンツも読み込みません。 |

## サードパーティサービス

当社の拡張機能は、サードパーティのサービスや解析ツールを統合・利用していません。

## 本プライバシーポリシーの変更

当社は、本プライバシーポリシーを随時更新することがあります。変更があった場合は、このページに新しいプライバシーポリシーを掲載し、本ポリシー冒頭の「最終更新日」を更新することでお知らせします。
