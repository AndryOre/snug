# Snug 隐私政策

最后更新：2026年10月6日

## 简介

Snug 致力于保护你的隐私。本隐私政策说明我们对通过浏览器扩展程序所获信息的收集、使用和披露方式。

## 信息的收集与使用

Snug 不会收集、存储或传输其用户的任何个人信息。我们的扩展程序完全在你的浏览器内运行，不会向外部服务器发送任何数据。

### 书签数据

- 扩展程序访问你的浏览器书签，仅用于将书签导出为 HTML、JSON、CSV、Markdown、OPML 或 XBEL 文件，或从 HTML、JSON、CSV 或 XBEL 文件、Chrome 配置文件的
  `Bookmarks`
  文件或 Safari 导出文件中导入书签。“重复项”页面也会读取你的书签以查找相同地址的副本，并且仅在你确认后才会删除。
- 只有在你主动发起导入或导出操作，或你配置的定时自动导出运行时，才会发生这种访问（参见下文“自动导出”）。
- 你的书签数据在你的设备上本地处理，不会传输给我们或任何第三方。

### 网站图标

- 为了在书签旁显示网站图标，扩展程序通过浏览器内置的 `_favicon`
  API 读取网站图标。这只是查找浏览器已缓存的图标，不会向我们或被收藏的网站发出任何网络请求。

### 自动导出

- 你可以选择启用书签的定时自动导出。启用后，扩展程序会按你配置的间隔导出书签，并使用浏览器的下载功能将生成的文件直接写入设备的“下载”文件夹，而不会弹出保存位置的提示。
- 只有在你明确启用自动导出并配置计划后才会这样做；该功能默认关闭。
- 保留：每次自动导出成功后，Snug 会删除其自己导出的、超出你所设数量的最旧文件（默认为 10 个；设为 0 则全部保留）。它只会删除自己保存的文件，绝不会触碰“下载”文件夹中的其他文件。
- 通知：如果自动导出失败，Snug 会在你的设备上显示系统通知并说明原因。你可以在“自动导出”页面中关闭此通知。导出成功时从不通知，且通知内容不会离开你的设备。

## 数据存储

- Snug 不会在外部服务器上存储任何用户数据，包括书签。
- 导出（手动或自动）过程中创建的任何文件，都会通过浏览器的下载功能直接保存到你的本地设备。手动导出使用标准的
  `<a download>` 链接，不需要 `downloads` 权限；自动导出和安全快照文件则使用
  `downloads` 权限。
- 扩展程序使用浏览器的本地存储（`storage.local`）保存你的本地偏好设置，例如主题、显示选项、导出选项、文件名模板和你的自动导出配置。这些数据保留在你的设备上，绝不会传输到任何地方。
- 在你首次成功导出之后，Snug 可能会在弹出窗口中显示一张仅出现一次、可关闭的卡片，邀请你在安装扩展程序所用的商店（Chrome 网上应用店或 Microsoft
  Edge 加载项）中为其评价。为了只显示一次，Snug 会在 `storage.local`
  中存储两个本地时间戳：卡片可显示的时间和你关闭它的时间。它们不包含书签内容、个人信息或任何标识符，也绝不会传输到任何地方。这张卡片只是一个链接：是否打开商店页面由你决定，Snug 本身不会为此发出任何网络请求。
- 在每次“恢复 — 替换”导入之前，以及每当你在设置中选择创建快照时，Snug 都会保存书签栏和其他书签的安全快照，以便撤销导入。这会将你的书签内容（标题、地址和文件夹结构）存储在浏览器的本地存储中，保留最近五个快照，并将每个快照另存为“下载”文件夹中的一个文件。这些内容绝不会离开你的设备。

## 权限

Snug 会请求以下浏览器权限，每项权限仅用于所述用途：

| 权限               | 用途                                                                                         |
| ------------------ | -------------------------------------------------------------------------------------------- |
| `bookmarks`        | 读取和写入你的浏览器书签，以支持导入和导出。                                                 |
| `favicon`          | 通过浏览器内置的 `_favicon` API 在书签旁显示网站图标。                                       |
| `storage`          | 将你的本地偏好设置保存在你的设备上。                                                         |
| `alarms`           | 按配置的间隔安排并触发书签的自动导出。                                                       |
| `downloads`        | 将自动导出和安全快照文件保存到你的设备，并删除 Snug 自己的旧自动导出文件（保留）。           |
| `notifications`    | 自动导出失败时在你的设备上显示通知。你可以将其关闭。                                         |
| `unlimitedStorage` | 在你的设备上保留最近五个书签安全快照，书签较多时这些快照可能很大。                           |
| `offscreen`        | 创建一个短暂存在的隐藏文档，以便将自动导出转换为可下载的文件。它没有界面，也不加载远程内容。 |

## 第三方服务

我们的扩展程序不会集成或使用任何第三方服务或分析工具。

## 本隐私政策的变更
