## 2.1.0

2026-10-08

- 가져오기가 크게 개선되었어요. 여러 파일을 한꺼번에 선택하거나 놓고, 트리로
  미리 본 뒤 가져올 항목을 정확히 고를 수 있어요. 툴바 팝업에서도 파일을 놓아
  가져올 수 있어요.

## 2.0.3

2026-10-06

- 이제 팝업은 첫 내보내기에 성공한 뒤 한 번만, 닫을 수 있는 리뷰 요청을
  표시해요.
- 개인정보처리방침에 리뷰 요청의 로컬 전용 상태에 대한 설명을 추가했어요.
- 팝업의 모양을 다듬었어요. 카드 테두리가 더 선명해지고, 라이트 모드에서 키보드
  포커스 링이 더 잘 보이며, 버튼과 메뉴의 전환이 더 부드러워졌어요.

## 2.0.2

2026-10-06

- 앱 사이드바에 Snug 웹사이트와 개인정보처리방침 링크를 추가했어요.
- 매니페스트의 확장 프로그램 홈페이지가 이제 웹사이트를 가리켜요.
- 웹사이트를 알리는 새로운 기능 항목을 추가했어요.

## 2.0.1

2026-10-04

- 스토어 설명을 10개 언어 모두에서 평이한 문장으로 읽히도록 다시 썼어요. 게시된
  적 없는 2.0.0 이후 기능상의 변경은 없어요.

## 2.0.0

2026-10-02

- 확장 프로그램의 이름이 새 이름과 새 아이콘의 **Snug**로 바뀌었어요. 모든 것이
  기기 안에서만 이루어진다는 약속은 그대로이며, 데이터와 설정은 바뀌지 않아요.
- 내보내기, 가져오기, 자동 내보내기, 설정, 새로운 기능을 오가는 사이드바가 있는
  새 앱을 추가했어요.
- 팝업을 더 간결하게 다시 디자인했어요.
- 확장 프로그램 전체에 새 Snug 색상 팔레트를 적용했어요.
- 새 언어 8개를 추가해 영어, 스페인어, 독일어, 프랑스어, 이탈리아어, 브라질
  포르투갈어, 러시아어, 일본어, 한국어, 중국어 간체로 총 10개 언어를 지원해요.
- 이제 복원하기 전에 북마크의 안전 스냅샷을 먼저 저장하며, 가져오기 페이지에서
  교체를 되돌릴 수 있어요.
- 중복 북마크를 찾아 직접 고른 것만 삭제할 수 있는 중복 페이지와, 가져올 때 쓰는
  중복 건너뛰기 옵션을 추가했어요.
- 자동 내보내기에 매시간과 매주 일정, 최근 백업만 남기는 보관 개수, 백업이
  실패했을 때의 알림이 생겼어요.
- Markdown, OPML, XBEL로 내보내기와 Chrome 프로필 Bookmarks 파일, XBEL, Safari
  북마크에서 가져오기를 추가했고, 진행률과 취소도 지원해요.
- 북마크가 아주 많아도 트리가 빠르게 동작하고, 키보드와 스크린 리더로 모든
  기능을 사용할 수 있게 했어요.

## 1.7.0

2026-10-01

- 자동 내보내기 설정에 상태 카드와 지금 내보내기 버튼을 추가했고, 팝업에는 자동
  내보내기가 켜져 있는지, 꺼져 있는지, 실패했는지 보여 주는 상태 줄을
  추가했어요.
- CSV, HTML, JSON 파일에서 허용되지 않는 URL 스킴(예: `javascript:`)을
  거부하도록 북마크 가져오기를 강화했어요.
