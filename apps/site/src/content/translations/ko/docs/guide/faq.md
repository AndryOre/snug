Snug에 대해 가장 자주 묻는 질문에 짧게 답해요.

## 파일 여러 개를 한 번에 가져올 수 있나요?

네. 가져오기 페이지나 툴바 팝업에서 파일 여러 개를 선택하거나 놓으면 Snug가 한
번에 가져와요.

## 왜 모든 북마크에 접근해야 하나요?

확장 프로그램이 북마크를 내보내고 가져오려면 읽기와 쓰기 권한이 있어야 해요.
Snug는 네트워크 호출을 하지 않으므로, 읽은 내용이 기기 밖으로 나갈 수 없어요.

## 어떤 형식을 지원하나요?

내보내기는 HTML, JSON, CSV, Markdown, OPML, XBEL을 지원해요. 가져오기는 HTML,
JSON, CSV, XBEL, Chrome 프로필의 `Bookmarks` 파일, Safari 내보내기 파일을
지원해요.

## 어떤 브라우저에서 쓸 수 있나요?

Chrome과 Edge, Brave, Opera 같은 다른 Chromium 브라우저에서 쓸 수 있어요.

## 개인 개발자의 확장 프로그램을 설치해도 안전한가요?

소스 코드는 공개돼 있고, CodeQL이 검사해요. 프로젝트에는 OpenSSF Scorecard와
Best Practices 배지가 있고, CI는 버전을 고정해 실행돼요. 공개 저장소에서 직접
확인해 보세요.

## 다운로드 폴더가 아닌 다른 폴더에 백업할 수 있나요?

네. [자동 내보내기](auto-export.md) 페이지에서 사용자 지정 폴더를 선택하세요.
브라우저를 다시 시작하면 Chrome이 접근 권한을 한 번 확인해요. 사람이 없어도
실행이 계속되게 하려면 "방문할 때마다 허용"을 선택하세요. 접근 권한이 없으면
Snug가 경고하고, 다른 곳에 저장하는 대신 실행이 실패해요.
