1. 팝업에서 빠른 가져오기:
   - 필요하면 기본 가져오기 방식을 바꿔요([**설정**](settings.md) 참고).
     처음에는 **복원 — 병합**으로 되어 있어요.
   - "파일 선택…"을 클릭해 북마크 파일을 하나 이상 선택하거나(아래 **가져올 수
     있는 파일** 참고), 팝업의 가져오기 영역에 파일을 놓아요. 드래그하는 동안
     "파일을 놓아 가져오기" 오버레이가 나타나요. 가져오기가 실행 중일 때 놓은
     파일은 무시돼요.
   - 확장 프로그램이 각 형식을 자동으로 감지하고, 기본 가져오기 방식으로
     북마크를 바로 가져와요. CSV 파일이나 북마크바/기타 북마크 데이터가 없는
     다른 파일은 기본 방식과 상관없이 항상 새 "가져온 북마크" 폴더로 가져와요.
   - 여러 파일은 하나의 **가져오기 일괄 작업**으로 함께 가져와요(아래 참고).
     Snug가 읽을 수 없는 파일은 제외돼요. 경고에는 건너뛴 파일이 최대 세 개까지
     `이름: 이유` 형식으로 나열되고, 그 뒤에 "외 N개"가 표시돼요.
   - 기본 방식이 **복원 — 교체**이면 팝업에는 기존 북마크가 교체된다는 인라인
     경고만 표시돼요. 파일을 고르면 앱의 **가져오기** 페이지가 열리고, 거기서
     교체 내용을 검토하고 확인해요(먼저 안전 스냅샷이 저장되므로 되돌릴 수
     있어요). 매우 큰 가져오기도 **가져오기** 페이지가 열려요.
2. 앱의 **가져오기** 페이지에서 먼저 미리보기:
   - 북마크 파일을 하나 이상 놓거나 선택해요. 각 파일은 감지된 형식과 북마크
     개수, 또는 읽을 수 없는 이유가 담긴 행으로 표시돼요. 파일을 제거하거나
     **파일 추가**로 더 추가할 수 있어요.
   - 항목별 미리보기에 가져왔을 때의 북마크 트리가 표시돼요. 중복 건너뛰기가
     제외할 북마크에는 `중복 · 건너뜀` 배지가 붙으므로, 아무것도 바뀌기 전에
     파일을 판단할 수 있어요.
   - 가져오기 방식을 고릅니다(기본값에 따라 미리 선택돼요).
     - **폴더 만들기**: 모든 북마크를 새 "가져온 북마크" 폴더에 추가해요.
       CSV처럼 복원할 폴더 구조가 없는 파일을 포함해 모든 파일에 사용할 수
       있어요.
     - **복원 — 병합**: 기존 북마크와 함께 원래 위치에 북마크를 배치해요. 위치
       데이터가 있는 JSON/HTML 파일에만 사용할 수 있어요.
     - **복원 — 교체**: 현재 북마크바와 기타 북마크를 먼저 비운 뒤 북마크를 원래
       위치로 복원해요. 위치 데이터가 있는 파일에만, 한 번에 파일 하나에
       대해서만 사용할 수 있어요.
   - "복원 — 교체"를 선택하면 교체로 제거되고 추가될 북마크 개수와 삭제될 북마크
     목록이 표시되며, 가져오기가 실행되기 전에 경고 대화 상자를 확인해야 해요.
   - **중복 건너뛰기**(기본값 켜짐)는 URL이 이미 브라우저에 있는 북마크를
     제외하고, 선택한 북마크 중 몇 개를 건너뛸지 알려 줘요. 폴더 만들기와 복원 —
     병합에 적용되며 복원 — 교체에는 적용되지 않아요. 이 스위치는 빠른
     가져오기와 공유돼요.

## 가져오기 선택

폴더 만들기와 복원 — 병합에서는 미리보기 트리에 체크박스가 있어요. 북마크 하나,
폴더 전체, 또는 둘을 섞어 체크하면 Snug는 **가져오기 선택** 항목만 가져와요.
복원 — 교체에는 선택이 없고 항상 전부 가져와요.

## 가져오기 일괄 작업

여러 파일을 한꺼번에 가져오면 하나의 **가져오기 일괄 작업**으로 실행돼요.
가져오기 방식, 미리보기, 진행률이 하나씩이에요. Snug는 기존 URL을 한 번만
확인하므로, 중복 건너뛰기는 두 파일에 모두 들어 있는 북마크도 제외해요.

- 폴더 만들기에서 파일이 둘 이상이면, 각 파일은 파일 이름(확장자 제외)을 딴 자기
  폴더로 들어가요. 파일이 하나면 "가져온 북마크" 폴더를 그대로 쓰고, CSV 파일은
  항상 이 폴더를 사용해요.
- 복원 — 교체에는 파일이 정확히 하나 필요해요. 파일이 둘 이상이면 두 번째 파일이
  첫 번째 파일을 지우게 되므로 이 방식은 사용할 수 없어요.
- 읽을 수 없는 파일은 미리보기 단계에서 제외되고 결과에 나열돼요.
- 취소하거나 도중에 실패하면 일괄 작업을 시작하기 전의 북마크 상태로 되돌아가요.

## 가져올 수 있는 파일

Snug는 파일의 MIME 유형, 확장자, 내용 순으로 형식을 감지해요. 다음을 읽을 수
있어요.

- Snug와 브라우저의 내보내기 파일: HTML(Netscape 북마크 파일), JSON, CSV, XBEL.
- Chrome 프로필의 `Bookmarks` 파일(Chrome 프로필 폴더 안의 원본 JSON 파일).
  폴더는 원래 위치로 들어가요.
- Safari 내보내기(HTML). 즐겨찾기는 북마크바가 되고, 읽기 목록과 Safari의 다른
  폴더는 기타 북마크에 남으며 읽기 목록은 자기 폴더에 들어가요.

## 안전 스냅샷과 되돌리기

복원 — 교체를 실행하기 전에 Snug는 북마크바와 기타 북마크의 **안전 스냅샷**을
저장해요. 다운로드 폴더의 JSON 파일(`snug-safety-snapshot-<date>.json`)과 확장
프로그램 안에 보관되는 사본이 있어요. 교체 확인 창에서 이 사실을 알려 주고
설정의 안전 스냅샷 카드로 연결해 줘요. 스냅샷을 저장할 수 없으면 아무것도
삭제되지 않아요.

- 교체한 뒤 결과 화면의 **가져오기 되돌리기**를 누르면 스냅샷이 복원돼요.
- **설정**의 안전 스냅샷 카드에는 최근 스냅샷 다섯 개가 나열돼요. 확인을 거쳐
  원하는 스냅샷을 복원하거나 다운로드할 수 있고, 언제든 새 스냅샷을 만들 수
  있어요.

Snug는 최근 스냅샷 다섯 개를 보관하므로 여섯 번째가 생기면 가장 오래된 것이
대체돼요. 다만 북마크가 들어 있는 가장 최근 스냅샷은 절대 삭제되지 않아요.
스냅샷 복원도 하나의 교체이므로, Snug는 먼저 현재 북마크의 새 스냅샷을 저장해요.
모든 것은 기기 안에 남고 Snug는 네트워크 요청을 하지 않아요.
