1. 빠른 내보내기: 팝업에서 형식을 고르고 "모두 내보내기"를 클릭하면 북마크 트리
   전체를 내보내요.
2. 내보낼 항목을 직접 정하려면 앱의 **내보내기** 페이지를 엽니다.
   - 검색창으로 특정 북마크를 찾아요.
   - 북마크나 폴더 전체를 체크해요("모두 선택"도 사용할 수 있어요).
   - **내보내기 옵션** 패널(파비콘, 날짜, 폴더 숨기기, 파일 이름 템플릿)을
     조정해요.
   - 내보내기 형식을 고르고 "북마크 N개 내보내기"를 클릭해요.

## 내보내기 형식

Snug는 여섯 가지 형식으로 내보내요.

| 형식     | 확장자  | 용도                                             |
| -------- | ------- | ------------------------------------------------ |
| HTML     | `.html` | 모든 브라우저로 가져오기(Netscape 북마크 파일).  |
| JSON     | `.json` | 폴더와 루트 위치를 그대로 유지한 채 Snug로 복원. |
| CSV      | `.csv`  | 스프레드시트. 북마크당 한 행, `folder` 열 포함.  |
| Markdown | `.md`   | 노트와 위키. 폴더는 제목과 목록이 돼요.          |
| OPML     | `.opml` | 피드 리더와 아웃라이너.                          |
| XBEL     | `.xbel` | XML 북마크 형식을 읽는 다른 북마크 관리자.       |

Markdown과 OPML은 내보내기 전용이라 Snug로 다시 가져올 수 없어요.

## 진행률과 취소

오래 걸리는 내보내기나 가져오기에는 진행 카드와 진행 개수가 표시돼요. 중단하려면
**취소**를 클릭하세요. 취소한 내보내기는 파일을 다운로드하지 않아요. 취소한
가져오기는 이미 추가한 북마크를 제거하고, 취소한 복원 — 교체는 안전 스냅샷에서
이전 북마크를 되돌려 놓아요. 가져오기 일괄 작업을 취소하면 일괄 작업을 시작하기
전의 북마크 상태로 돌아가요.

## 내보낸 파일 이름 지정

기본적으로 내보낸 파일의 이름은 `Bookmarks_<date>_<time>`이에요(예:
`Bookmarks_2026-10-03_14-05-09`). 이름을 바꾸려면 다음과 같이 하세요.

1. 앱의 **내보내기** 페이지를 엽니다(같은 패널이 **자동 내보내기**에도 있어요).
2. **내보내기 옵션**에서 "파일 이름 템플릿"을 편집합니다. 입력하는 동안 결과
   파일 이름이 실시간 미리보기로 표시돼요.
3. 현재 날짜와 시간을 넣으려면 다음 자리 표시자를 사용하세요(대소문자 구분
   없음).

   | 자리 표시자 | 값           |
   | ----------- | ------------ |
   | `%yyyy`     | 연도 (4자리) |
   | `%yy`       | 연도 (2자리) |
   | `%mm`       | 월           |
   | `%dd`       | 일           |
   | `%hh`       | 시           |
   | `%min`      | 분           |
   | `%sec`      | 초           |

   예를 들어 `%yyyy%mm%dd myPc`는 `20260930 myPc.html`을 만들어요(다른
   형식에서는 해당하는 확장자가 붙어요).

템플릿은 파일 이름이 만들어지는 모든 곳에 적용돼요. 팝업의 기본 내보내기,
내보내기 페이지, 자동 내보내기가 모두 해당해요. 파일 이름에 쓸 수 없는
문자(`/ \ : * ? " < > |`)는 `_`로 바뀌고, 템플릿이 비어 버리면 "Bookmarks"로
대체돼요.
