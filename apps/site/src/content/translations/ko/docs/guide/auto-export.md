---
title: 자동 내보내기
sourceHash: 5eb2acaa2e4867cc
---

Snug는 직접 조작하지 않아도 일정에 따라 북마크를 내보낼 수 있어요.

1. 앱의 **자동 내보내기** 페이지를 엽니다.
2. 자동 내보내기를 켜고, 여섯 가지 형식 중 하나 이상, 저장 위치(다운로드 또는
   사용자 지정 폴더), 간격, 그리고 내보낸 파일을 저장할 하위 폴더 경로(선택)를
   정해요. 간격은 매시간, 12시간마다, 매일, 3일마다, 매주 중에서 고를 수 있어요.
   매일, 3일마다, 매주 실행은 원하는 시간에 이루어지고, 매주 실행은 요일도 고를
   수 있어요. 매시간과 12시간마다 실행은 시간 설정을 무시해요.
3. 그 뒤로 확장 프로그램이 그 일정에 따라 북마크를 내보내고, 저장 대화 상자나
   추가 확인 없이 파일을 선택한 위치(기본값은 다운로드 폴더)에 바로 저장해요.
   예약된 내보내기 시각에 브라우저가 닫혀 있었거나 확장 프로그램을 사용할 수
   없었다면, 다음 예약 시각을 기다리지 않고 브라우저가 다음에 시작된 직후
   자동으로 따라잡아요.

**저장 위치**는 파일을 저장할 곳을 정해요. **다운로드**(기본값)는 브라우저의
다운로드 폴더에 저장해요. **사용자 지정 폴더**는 컴퓨터 어디에서든 고른 폴더에
저장해요. **폴더 선택…**을 누르고, 나중에 **폴더 변경**으로 다른 폴더를 고를 수
있어요. 언제든 **다운로드**를 다시 선택하면 돌아가요. 하위 폴더 경로는 저장
위치를 기준으로 한 상대 경로라서, 고른 폴더 안의 폴더를 가리켜요. 같은 이름의
파일이 이미 있으면 Snug가 " (1)" 접미사를 붙이고 덮어쓰지 않아요.

브라우저를 처음 다시 시작한 뒤에 Chrome이 사용자 지정 폴더에 대한 접근 권한을 한
번 확인해요. 사람이 없어도 실행이 계속되게 하려면 "방문할 때마다 허용"을
선택하세요.

폴더 접근 권한이 없으면 브라우저가 시작될 때 Snug가 경고해요. 그러면 팝업과
**자동 내보내기** 페이지에 "폴더 접근 권한이 필요합니다"와 **접근 허용** 버튼이
표시돼요. 접근을 허용하기 전까지 실행은 실패하고, 대신 다운로드에 저장되지도
않아요.

**최근 N회 실행분 유지**(보관 개수, 기본값 10)는 내보내기 파일이 쌓이는 양을
제한해요. 실행이 성공할 때마다 Snug는 다운로드와 사용자 지정 폴더를 합쳐 가장
최근 N회분을 유지하고, 그보다 오래된 실행분의 파일을 삭제해요(유지되는 실행분은
모든 형식이 그대로 남아요). 다운로드에 저장한 파일은 브라우저 다운로드 기록의
해당 항목도 함께 삭제돼요. Snug가 직접 저장한 파일만 삭제하며 폴더의 다른 파일은
절대 건드리지 않고, 이미 삭제했거나 옮긴 파일은 그냥 건너뛰어요. 폴더를 바꾸면
이전 폴더의 파일은 그대로 남아요. 실패한 실행은 아무것도 삭제하지 않아요. 0으로
설정하면 모두 보관해요.

**내보내기 실패 시 알림**(기본값 켜짐)은 실행이 실패하면 "Snug · 자동 내보내기
실패"라는 제목과 이유가 담긴 시스템 알림을 표시해요. 알림을 클릭하면 자동
내보내기 페이지가 열려요. 성공한 실행은 알리지 않고, 반복된 실패는 이전 알림을
쌓지 않고 대체해요. 예약 실행이나 따라잡기 실행이 실패하면 다음 실행이 성공할
때까지 툴바 아이콘에 "!" 배지도 표시돼요.

**자동 내보내기** 페이지의 변경 사항은 자동으로 저장돼요. 상태 카드는 아래에
저장되지 않은 변경 사항이 있어도 그와 상관없이 실제 예약 상태를 항상 보여 줘요.

- **마지막 실행** — 자동 내보내기가 마지막으로 실행된 시각과 결과, 실패한 경우
  저장된 오류 메시지예요. 팝업의 자동 내보내기 상태 행에도 다음 실행이나 실패
  알림이 표시돼요.
- **다음 실행** — 다음 실행 예정 시각이에요. 자동 내보내기가 꺼져 있으면 "자동
  내보내기가 꺼져 있어요"가 표시돼요.

**지금 내보내기**는 사용 스위치가 꺼져 있어도 화면에 현재 선택된 형식과 경로로
즉시 내보내기를 실행해요. 실행 중에는 스피너가 표시되고, 끝나면 성공 또는 오류
메시지가 잠깐 나타나며, 상태 카드의 "마지막 실행" 행도 그에 맞게 갱신돼요. 이
기능은 자동 일정이나 다음 예정 시각을 바꾸지 않아요.
