## 앱 열기

확장 프로그램 아이콘을 클릭해 팝업을 열고 "앱 열기"를 누르면 전체 페이지 앱이
열려요(브라우저의 확장 프로그램 옵션에서도 열 수 있어요). 사이드바에서
**내보내기**, **가져오기**, **중복**, **자동 내보내기**, **설정**, **새로운
기능**을 오갈 수 있어요. **환영합니다** 둘러보기는 처음 설치할 때 열려요. 이전
버전 Snug의 페이지는 해당하는 앱 페이지로 리디렉션되므로, 예전에 해 둔 북마크도
계속 작동해요.
