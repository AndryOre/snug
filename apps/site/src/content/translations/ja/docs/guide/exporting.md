1. クイック書き出し: ポップアップで形式を選び、「すべて書き出す」をクリックすると、ブックマークツリー全体を書き出せます。
2. 書き出す内容を細かく選ぶには、アプリの **書き出し** ページを開きます。
   - 検索ボックスで特定のブックマークを探せます。
   - ブックマークや、フォルダごとにチェックします（「すべてのブックマークを選択」も使えます）。
   - **書き出しオプション**
     パネル（ファビコン、日付、フォルダの非表示、ファイル名テンプレート）を調整します。
   - 書き出し形式を選び、「N 件のブックマークを書き出す」をクリックします。

## 書き出し形式

Snug は 6 つの形式で書き出せます。

| 形式     | 拡張子  | 適した用途                                                           |
| -------- | ------- | -------------------------------------------------------------------- |
| HTML     | `.html` | あらゆるブラウザへの読み込み（Netscape ブックマークファイル）。      |
| JSON     | `.json` | フォルダとルートの場所を保ったまま Snug に復元。                     |
| CSV      | `.csv`  | スプレッドシート。1 行が 1 ブックマークで、`folder` 列を含みます。   |
| Markdown | `.md`   | メモや Wiki。フォルダは見出しとリストになります。                    |
| OPML     | `.opml` | フィードリーダーやアウトライナー。                                   |
| XBEL     | `.xbel` | XML のブックマーク形式を読み込める、ほかのブックマークマネージャー。 |

Markdown と OPML は書き出し専用です。Snug にはこれらを読み込み直す機能はありません。

## 進行状況とキャンセル

時間のかかる書き出しや読み込みでは、件数が増えていく進行状況カードが表示されます。
**キャンセル**
をクリックすると中止できます。書き出しをキャンセルすると、ファイルはダウンロードされません。読み込みをキャンセルすると、すでに追加したブックマークが削除され、復元 — 置き換えをキャンセルすると、安全スナップショットから以前のブックマークが戻ります。読み込みバッチをキャンセルすると、ブックマークはバッチの開始前の状態に戻ります。

## 書き出したファイルの名前

既定では、書き出したファイルの名前は `Bookmarks_<date>_<time>` になります（例:
`Bookmarks_2026-10-03_14-05-09`）。変更するには次の手順にします。

1. アプリの **書き出し** ページを開きます（同じパネルは **自動書き出し**
   にもあります）。
2. **書き出しオプション**
   で「ファイル名テンプレート」を編集します。入力するたびに、できあがるファイル名がライブプレビューで表示されます。
3. 次のプレースホルダー（大文字小文字は区別されません）で、現在の日付と時刻を含められます。

   | プレースホルダー | 値         |
   | ---------------- | ---------- |
   | `%yyyy`          | 年（4 桁） |
   | `%yy`            | 年（2 桁） |
   | `%mm`            | 月         |
   | `%dd`            | 日         |
   | `%hh`            | 時         |
   | `%min`           | 分         |
   | `%sec`           | 秒         |

   たとえば `%yyyy%mm%dd myPc` からは `20260930 myPc.html`
   が作られます（ほかの形式では、対応する拡張子になります）。

テンプレートは、ファイル名が作られるすべての場面で使われます。ポップアップからの基本の書き出し、書き出しページ、自動書き出しです。ファイル名に使えない文字（`/ \ : * ? " < > |`）は
`_` に置き換えられ、テンプレートが空になった場合は「Bookmarks」が使われます。
