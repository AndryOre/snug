1. Быстрый импорт из всплывающего окна:
   - При желании измените режим импорта по умолчанию (см.
     [**Настройки**](settings.md)) — изначально это **Восстановить —
     объединить**.
   - Нажмите «Выбрать файлы…» и выберите один или несколько файлов закладок (см.
     **Источники импорта** ниже) или перетащите их в раздел импорта всплывающего
     окна. Во время перетаскивания появляется наложение «Перетащите файлы для
     импорта». Файлы, перетащенные во время выполнения импорта, игнорируются.
   - Расширение автоматически определяет формат каждого файла и сразу
     импортирует закладки в режиме импорта по умолчанию. Файл CSV — или любой
     другой файл без данных о панели закладок или других закладках — всегда
     импортируется в новую папку «Импортированные закладки», независимо от
     режима по умолчанию.
   - Несколько файлов импортируются вместе как один **пакет импорта** (см.
     ниже). Файл, который Snug не может прочитать, пропускается. Предупреждение
     перечисляет до трёх пропущенных файлов в виде `name: reason`, а затем «и
     ещё N».
   - Если режим по умолчанию — **Восстановить — заменить**, всплывающее окно
     показывает только встроенное предупреждение о том, что ваши существующие
     закладки будут заменены. После выбора файла открывается страница **Импорт**
     приложения, где вы просматриваете замену и подтверждаете её (сначала
     сохраняется страховой снимок, поэтому вы сможете отменить импорт). Очень
     большие импорты также открываются на странице **Импорт**.
2. Сначала предпросмотр, на странице **Импорт** приложения:
   - Перетащите или выберите один или несколько файлов закладок. Каждый файл
     получает строку с определённым форматом и количеством закладок или с
     причиной, по которой его не удалось прочитать. Вы можете убрать файл или
     добавить другие через **Добавить файлы**.
   - Подробный предпросмотр показывает дерево закладок в том виде, в каком оно
     будет импортировано. Закладки, которые «Пропускать дубликаты» оставит без
     внимания, помечены значком `Дубликат · пропущен`, так что вы можете оценить
     файл до каких-либо изменений.
   - Выберите режим импорта (заранее выбран ваш режим по умолчанию):
     - **Создать папку**: добавляет все закладки в новую папку «Импортированные
       закладки». Доступно для любого файла, включая CSV (в нём нет структуры
       папок, которую можно восстановить).
     - **Восстановить — объединить**: размещает закладки на их прежних местах
       рядом с уже существующими. Доступно только для файлов JSON/HTML с данными
       о расположении.
     - **Восстановить — заменить**: сначала очищает вашу текущую панель закладок
       и «Другие закладки», затем возвращает закладки на прежние места. Доступно
       только для файлов с данными о расположении и только для одного файла за
       раз.
   - При выборе «Восстановить — заменить» показывается, сколько закладок замена
     удалит и добавит, перечисляются закладки, которые будут удалены, и перед
     выполнением импорта требуется подтвердить предупреждение.
   - **Пропускать дубликаты** (включено по умолчанию) оставляет без внимания
     любую закладку, URL которой уже есть в вашем браузере, и сообщает, сколько
     из выбранных закладок будет пропущено. Параметр действует для режимов
     «Создать папку» и «Восстановить — объединить», но не для «Восстановить —
     заменить». Переключатель общий с быстрым импортом.

## Выбор для импорта

В режимах «Создать папку» и «Восстановить — объединить» у дерева предпросмотра
есть флажки. Отметьте отдельные закладки, целые папки или то и другое, и Snug
импортирует только **выбранное для импорта**. У «Восстановить — заменить» выбора
нет: он всегда импортирует всё.

## Пакет импорта

Несколько файлов, импортируемых одновременно, выполняются как один **пакет
импорта**: один режим импорта, один предпросмотр и один индикатор хода
выполнения. Snug проверяет существующие URL один раз, поэтому «Пропускать
дубликаты» также оставляет без внимания закладку, которая встречается в двух
файлах.

- В режиме «Создать папку» при двух и более файлах каждый файл попадает в
  собственную папку, названную по файлу (без расширения). Один файл сохраняет
  папку «Импортированные закладки», а файлы CSV всегда используют её.
- «Восстановить — заменить» требует ровно один файл. При двух и более файлах он
  отключён, потому что второй файл стёр бы первый.
- Файл, который не удаётся прочитать, исключается на этапе предпросмотра и
  указывается в результате.
- Отмена или сбой на полпути возвращает ваши закладки в состояние, в котором они
  были до начала пакета.

## Источники импорта

Snug определяет формат по MIME-типу файла, затем по расширению, затем по
содержимому. Он читает:

- Экспорт из Snug и браузеров: HTML (файл закладок Netscape), JSON, CSV и XBEL.
- Файл `Bookmarks` профиля Chrome (исходный файл JSON внутри папки профиля
  Chrome). Его папки попадают на свои прежние места.
- Экспорт из Safari (HTML). «Избранное» становится панелью закладок; «Список для
  чтения» и остальные папки Safari остаются в «Других закладках», причём «Список
  для чтения» — в собственной папке.

## Страховой снимок и отмена импорта

Перед каждым «Восстановить — заменить» Snug сохраняет **страховой снимок** вашей
панели закладок и «Других закладок»: файл JSON в папке «Загрузки»
(`snug-safety-snapshot-<date>.json`) и копию, хранящуюся внутри расширения.
Подтверждение замены сообщает об этом и ссылается на карточку страховых снимков
в настройках. Если снимок не удаётся сохранить, ничего не удаляется.

- После замены **Отменить импорт** в результате восстанавливает снимок.
- В **Настройках** карточка страховых снимков перечисляет последние пять
  снимков. Вы можете восстановить или скачать любой из них после подтверждения и
  в любой момент создать новый.

Snug хранит последние пять снимков, поэтому шестой заменяет самый старый, за тем
исключением, что самый новый снимок, содержащий какие-либо закладки, никогда не
удаляется. Восстановление снимка само по себе является заменой, поэтому Snug
сначала сохраняет новый снимок ваших текущих закладок. Всё остаётся на вашем
устройстве, а Snug не выполняет сетевых запросов.
