1. Быстрый экспорт: во всплывающем окне выберите формат и нажмите
   «Экспортировать все», чтобы экспортировать всё дерево закладок.
2. Чтобы управлять тем, что экспортируется, откройте страницу **Экспорт** в
   приложении:
   - Используйте поле поиска, чтобы найти нужные закладки.
   - Отметьте отдельные закладки или целые папки (или нажмите «Выбрать все»).
   - Настройте панель **Параметры экспорта** (значки сайтов, даты, скрытие
     папок, шаблон имени файла).
   - Выберите формат экспорта и нажмите «Экспортировать N закладок».

## Форматы экспорта

Snug экспортирует шесть форматов:

| Формат   | Расширение | Подходит для                                                       |
| -------- | ---------- | ------------------------------------------------------------------ |
| HTML     | `.html`    | Импорта в любой браузер (файл закладок Netscape).                  |
| JSON     | `.json`    | Восстановления в Snug с сохранением папок и корневых расположений. |
| CSV      | `.csv`     | Электронных таблиц; одна строка на закладку со столбцом `folder`.  |
| Markdown | `.md`      | Заметок и вики; папки становятся заголовками и списками.           |
| OPML     | `.opml`    | Программ для чтения лент и редакторов структуры.                   |
| XBEL     | `.xbel`    | Других менеджеров закладок, читающих XML-формат закладок.          |

Markdown и OPML поддерживают только экспорт: Snug не может импортировать их
обратно.

## Ход выполнения и отмена

Длительный экспорт или импорт показывает карточку хода выполнения со счётчиком.
Нажмите **Отмена**, чтобы остановить. Отменённый экспорт не скачивает файл.
Отменённый импорт удаляет уже добавленные закладки, а отменённое «Восстановить —
заменить» возвращает ваши прежние закладки из страхового снимка. Отмена пакета
импорта возвращает ваши закладки в состояние, в котором они были до начала
пакета.

## Именование экспортируемых файлов

По умолчанию экспортируемые файлы называются `Bookmarks_<date>_<time>`
(например, `Bookmarks_2026-10-03_14-05-09`). Чтобы изменить это:

1. Откройте страницу **Экспорт** в приложении (та же панель есть и на странице
   **Автоэкспорт**).
2. В **Параметрах экспорта** измените «Шаблон имени файла». Живой предпросмотр
   показывает получающееся имя файла по мере ввода.
3. Используйте эти подстановки (без учёта регистра), чтобы включить текущие дату
   и время:

   | Подстановка | Значение |
   | ----------- | -------- |
   | `%yyyy`     | Год (4)  |
   | `%yy`       | Год (2)  |
   | `%mm`       | Месяц    |
   | `%dd`       | День     |
   | `%hh`       | Час      |
   | `%min`      | Минута   |
   | `%sec`      | Секунда  |

   Например, `%yyyy%mm%dd myPc` даёт `20260930 myPc.html` (и соответствующее
   расширение для других форматов).

Шаблон применяется везде, где создаётся имя файла: при базовом экспорте из
всплывающего окна, на странице «Экспорт» и в автоэкспорте. Символы, недопустимые
в именах файлов (`/ \ : * ? " < > |`), заменяются на `_`, а шаблон, который
оказывается пустым, заменяется на «Bookmarks».
