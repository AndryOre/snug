1. 快速导出：在弹出窗口中选择一种格式并点击“全部导出”，即可导出整个书签树。
2. 如需控制导出的内容，请打开应用的**导出**页面：
   - 使用搜索框查找特定书签。
   - 勾选单个书签或整个文件夹（也可以使用“选择所有书签”）。
   - 调整**导出选项**面板（图标、日期、隐藏文件夹、文件名模板）。
   - 选择导出格式并点击“导出 N 个书签”。

## 导出格式

Snug 支持导出六种格式：

| 格式     | 扩展名  | 适用场景                                   |
| -------- | ------- | ------------------------------------------ |
| HTML     | `.html` | 导入任意浏览器（Netscape 书签文件）。      |
| JSON     | `.json` | 恢复到 Snug，并完整保留文件夹和根位置。    |
| CSV      | `.csv`  | 电子表格；每个书签一行，带有 `folder` 列。 |
| Markdown | `.md`   | 笔记和维基；文件夹会变成标题和列表。       |
| OPML     | `.opml` | 订阅阅读器和大纲工具。                     |
| XBEL     | `.xbel` | 其他可读取 XML 书签格式的书签管理器。      |

Markdown 和 OPML 仅支持导出：Snug 无法将它们导入回来。

## 进度与取消

耗时较长的导出或导入会显示带有实时计数的进度卡片。点击**取消**即可停止。取消的导出不会下载任何文件。取消的导入会移除已添加的书签，取消的“恢复——替换”会从安全快照中放回你之前的书签。取消导入批次会让你的书签恢复到批次开始之前的样子。

## 为导出文件命名

默认情况下，导出的文件名为 `Bookmarks_<date>_<time>`（例如
`Bookmarks_2026-10-03_14-05-09`）。如需自定义：

1. 打开应用的**导出**页面（同样的面板也出现在**自动导出**中）。
2. 在**导出选项**中编辑“文件名模板”。输入时，实时预览会显示最终的文件名。
3. 使用以下占位符（不区分大小写）来包含当前日期和时间：

   | 占位符  | 值         |
   | ------- | ---------- |
   | `%yyyy` | 年（4 位） |
   | `%yy`   | 年（2 位） |
   | `%mm`   | 月         |
   | `%dd`   | 日         |
   | `%hh`   | 时         |
   | `%min`  | 分         |
   | `%sec`  | 秒         |

   例如，`%yyyy%mm%dd myPc` 会生成
   `20260930 myPc.html`（其他格式则使用对应的扩展名）。

模板适用于所有生成文件名的地方：弹出窗口中的基本导出、导出页面和自动导出。文件名中不允许的字符（`/ \ : * ? " < > |`）会被替换为
`_`，最终为空的模板会回退为“Bookmarks”。
