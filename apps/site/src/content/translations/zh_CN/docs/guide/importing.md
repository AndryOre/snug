1. 快速导入，在弹出窗口中进行：
   - 可以先更改默认导入方式（参见[**设置**](settings.md)），它初始为**恢复——合并**。
   - 点击“选择文件…”并选择一个或多个书签文件（参见下文的**导入来源**），或将它们拖放到弹出窗口的导入区域。拖动时会出现“拖放文件以导入”的提示层。导入进行期间拖放的文件会被忽略。
   - 扩展程序会自动检测每个文件的格式，并立即按默认导入方式导入书签。CSV 文件，或任何没有书签栏／其他书签数据的文件，无论默认方式如何，都会导入到新的“导入的书签”文件夹中。
   - 多个文件会作为一个**导入批次**一起导入（见下文）。Snug 无法读取的文件会被排除。警告中最多列出三个被跳过的文件，格式为
     `name: reason`，之后是“以及另外 N 个”。
   - 如果默认方式是**恢复——替换**，弹出窗口只会显示一条行内警告，提示你现有的书签将被替换。选择文件后会打开应用的**导入**页面，你可以在那里查看替换内容并确认（会先保存安全快照，因此可以撤销）。非常大的导入同样会打开**导入**页面。
2. 先预览，在应用的**导入**页面中进行：
   - 拖放或选择一个或多个书签文件。每个文件会有一行，显示检测到的格式和书签数量，或无法读取的原因。你可以移除某个文件，也可以使用**添加文件**添加更多。
   - 逐项预览会显示书签树导入后的样子。会被“跳过重复项”排除的书签带有
     `重复 · 已跳过` 标记，因此你可以在任何内容发生变化之前评估该文件。
   - 选择一种导入方式（默认已按你的默认设置预先选中）：
     - **创建文件夹**：将所有书签添加到新的“导入的书签”文件夹。适用于任何文件，包括 CSV（它没有可恢复的文件夹结构）。
     - **恢复——合并**：将书签放回原位置，与现有书签并存。仅适用于带有位置数据的 JSON／HTML 文件。
     - **恢复——替换**：先清除当前的书签栏和其他书签，再将书签恢复到原位置。仅适用于带有位置数据的文件，并且一次只能使用一个文件。
   - 选择“恢复——替换”后，会显示替换将移除和添加多少个书签，列出将被删除的书签，并要求在导入运行前确认一个警告对话框。
   - **跳过重复项**（默认开启）会排除任何网址已存在于你的浏览器中的书签，并告诉你所选书签中有多少会被跳过。它适用于创建文件夹和恢复——合并，不适用于恢复——替换。该开关与快速导入共用。

## 导入选择

在“创建文件夹”和“恢复——合并”中，预览树带有复选框。你可以勾选单个书签、整个文件夹或两者混合，Snug 只会导入这个**导入选择**。“恢复——替换”没有选择：它总是导入全部内容。

## 导入批次

一次导入多个文件会作为一个**导入批次**运行：一种导入方式、一个预览和一个进度。Snug 只检查一次已有的网址，因此“跳过重复项”也会排除在两个文件中同时出现的书签。

- 在“创建文件夹”中导入两个或更多文件时，每个文件都会放入以文件名（不含扩展名）命名的文件夹。单个文件仍使用“导入的书签”文件夹，CSV 文件始终使用该文件夹。
- “恢复——替换”只能使用一个文件。有两个或更多文件时它会被禁用，因为第二个文件会抹掉第一个文件。
- 无法读取的文件会在预览时被排除，并列在结果中。
- 取消，或中途失败，都会让你的书签恢复到批次开始之前的样子。

## 导入来源

Snug 会先根据文件的 MIME 类型检测格式，然后是扩展名，最后是内容。它可以读取：

- Snug 和浏览器的导出文件：HTML（Netscape 书签文件）、JSON、CSV 和 XBEL。
- Chrome 配置文件中的 `Bookmarks`
  文件（Chrome 配置文件夹内的原始 JSON 文件）。其文件夹会放回原来的位置。
- Safari 导出文件（HTML）。“收藏夹”会成为书签栏；“阅读列表”和 Safari 的其他文件夹会留在其他书签中，其中“阅读列表”单独放在自己的文件夹里。

## 安全快照与撤销

每次“恢复——替换”之前，Snug 都会保存书签栏和其他书签的**安全快照**：一个位于“下载”文件夹中的 JSON 文件（`snug-safety-snapshot-<date>.json`），以及保存在扩展程序内部的一份副本。替换确认对话框会告知你这一点，并链接到设置中的安全快照卡片。如果快照无法保存，则不会删除任何内容。

- 替换之后，结果中的**撤销导入**会恢复该快照。
- 在**设置**中，安全快照卡片会列出最近的五份快照。确认之后，你可以恢复或下载其中任何一份，也可以随时新建一份。

Snug 保留最近的五份快照，因此第六份会替换最旧的一份，但包含书签的最新快照永远不会被丢弃。恢复快照本身就是一次替换，因此 Snug 会先为你当前的书签保存一份新的快照。所有内容都保留在你的设备上，Snug 不会发出任何网络请求。
